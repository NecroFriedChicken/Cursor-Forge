🖱️ Cursor Forge

Turn your own PNG, JPEG or GIF into a mouse cursor theme for Linux. Everything runs in your browser; nothing is uploaded.

How this page works (start here)
  1. Pick a cursor from the grid below. Each tile is one of the pointers Linux uses (arrow, hand, text, busy, resize…). The tiles show simple built-in defaults.
  2. Choose your image in the window that opens. Pick one image, or several images (they become animation frames, ordered by file name), or an animated GIF.
  3. Set the hotspot: tap or drag on the preview to mark the exact pixel that counts as the click point (for an arrow, its tip).
  4. If there is more than one frame, a speed slider appears. Drag it to change the time per frame.
  5. Repeat for any cursors you want to change. Choose your Linux type and sizes, name your theme, then press Build & download.

Tip: use a square-ish image with a transparent background (PNG or GIF). Images are scaled to fit a square, so a 128×128 or larger source looks best. Animated GIFs need a Chromium-based browser (Chrome, Edge, Brave); in other browsers upload the frames as separate images instead.

How to install your cursor file

The download is a .zip containing a standard Xcursor theme, which works on X11 and Wayland. Steps for the selected Linux type:

    Not changing? Log out and back in. Flatpak/Snap apps may need the theme in ~/.icons as well. For all users run sudo cp -r NAME /usr/share/icons/.

    Tap or drag the preview to set the hotspot.

    Left = fast, right = slow (time per frame)
